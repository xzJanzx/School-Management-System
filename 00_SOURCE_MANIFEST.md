# SMS — CLEAN ORIGINAL SOURCE OF TRUTH
Version: 1.0
Purpose: Clean, agent-neutral project source package.

## Included
- Core project/foundation documents
- Student Affairs specifications/decomposition source
- Academic Structure source
- Project context
- Approved decisions extracted from explicit project decisions
- Historical context kept separately

## Explicitly excluded
- حل مشكلة حصة Gemini.txt
- Agent quota troubleshooting
- Agent-specific repair instructions
- Agent-specific operational commands
- Any file whose primary purpose is troubleshooting an AI agent

## Important
Historical context is retained only when it helps explain SMS decisions. It is not a license to change current requirements.

## Usage
Give an AI agent this package as the SMS project source-of-truth package.
The agent must read the authoritative documents before implementation.
