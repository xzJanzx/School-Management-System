## Mandatory Architecture Rules
Reuse existing project infrastructure.
Do not create a second database, migration framework, auth system, permission
framework, or audit system.

Do not implement Enrollment, Promotion, Transfer, Attendance, Exams, Finance,
HR or Notifications.

## Completion Rule
Implementation is not acceptance. Verification and independent acceptance are
separate stages.
