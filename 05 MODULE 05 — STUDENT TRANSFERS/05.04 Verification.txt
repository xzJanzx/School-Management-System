## GAP-01 — High Severity
Affected area:
src/tests/smsModule05TestSuite.ts

Root cause:
The test setup creates students without explicitly supplying placement IDs from
the freshly created isolated academic hierarchy. createStudent() falls back to
hardcoded IDs such as STG-PRIM, GRD-P1, CLS-P1-A, AY-2025-2026. Those IDs do not
exist in the reset test database.

SQLite foreign-key enforcement rejects student creation. The setup catch block
then leaves student1Id/student2Id empty, causing downstream transfer gates to
reference an empty student ID.
