# SMS — Foundation Repository Rules

1. The original uploaded foundation documents are authoritative source material.
2. Derived navigation documents do not override original source documents.
3. Module-specific decomposition belongs in the separate Module 01–05 packages.
4. No implementation is authorized by this Foundation package.
5. Do not invent unsupported requirements.
6. Do not add troubleshooting, quota incidents, agent comparisons, or temporary
   execution reports to Source of Truth.
