# SMS — Module 01 — Student Master Data

## Standalone module package

This ZIP is intentionally self-contained so it can be uploaded/combined
independently with the other SMS module ZIPs.

### Important
- Original uploaded source files are preserved under `source/`.
- No Gemini/Antigravity troubleshooting files are included.
- No implementation code, databases, secrets, or runtime data are included.
- Where a source document contains material for multiple modules, the original
  file is preserved intact rather than silently deleting unrelated content.
- Module-specific extracts are clearly marked as extracts and do not replace
  the original source.
